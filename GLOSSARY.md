# splicewire/laravel-beam-docs

Language for reader-facing documentation and agent instructions.

## Language

**Local-environment posture**:
how one operator's machine runs commands (debugger mode, which
PHP binary, a local tool's prefix). It belongs to agent instructions and never appears in product docs.

**Product docs**:
the prose a host serves, or a starter ships, to its readers, as distinct
from agent instructions and rig evidence.
